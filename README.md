## 选择安装包

- **Mac：Apple 芯片，macOS 14 或更新**。下载 `for-macOS-arm64.zip`。Mac 为 build 56，已签名并通过 Apple 公证；本版启用应用内下载和确认安装，保留 GitHub 下载选项，修复 ZIP 中文应用名乱码。配置完成后提供保存工作、正常重启浏览器或 Claude 桌面端的入口；设置匹配仍不代表完整保护实测通过。
- **Windows：x64**。下载 `for-Windows-10-11-x64-Setup.exe`，退出旧版后运行安装器。本版启用应用内下载校验与确认安装，并验证原生运行及保留资料的覆盖升级。Windows 10/11 客户设备仍需继续验收；当前原生测试环境为 Windows Server 2022。

请选择版本页 Assets 中的安装文件，Source code 不是安装包。Windows 安装器尚无发布者签名；若系统阻止运行，请保留提示联系提供方核对。

## Mac 0.5.29 或更早版本的首次升级

先保存工作，正常退出所选浏览器、Claude 桌面端和 Claude Code。若 CEGR 专用连接正在运行，在旧助手「本机状态 → 诊断与维护」点击「暂停连接」，确认服务停止后退出助手。保留原应用和本机配置备份，再用访达将新应用覆盖到原来的「应用程序」位置。

打开新版后只点击一次「重新连接」，服务重启可能等待 15–40 秒；等本轮连接检查通过后再继续设置。系统扩展已经授权的用户无需重复授权。不要点击「恢复原配置」或清空账号、连接资料。暂停失败、应用仍在使用或系统拒绝时请保留提示，先联系支持。不要关闭系统安全保护。

如果连接未通过，查看失败原因和「连接问题详情」，向客服提供「复制连接诊断」中的信息；不要重复系统授权或连续重连。自动重新检查时，软件会保留最近一次失败及时间。

看到「连接复核中」时，请等待自动重试。只有最近已验证的连接才会短时保留，原验证最多有效 60 秒，失败不会延长有效期；到期或发现出口不符、授权失效、网络变化等问题时，助手会关闭专用连接。软件不会自动改用直连或其他出口。

## 应用设置尚未匹配时

Mac 客户版自带橙格网络保护扩展，无需额外安装 LuLu。打开「本机状态 → 查看保护检查」或「继续应用设置」，所有剩余步骤都在同一个面板里。

1. 保存并结束所选应用中的工作，完全退出应用。按面板提示完成组件更新、系统授权，等待专用连接核验。
2. 在「完成应用连接设置」点击「开始配置所选应用」。助手会准备设置，不需要输入命令。
3. 如需安装，点击「打开设备管理」，选中「橙格 CEGR · 应用专用出口」并点击「安装」；系统密码由本人输入。仅打开文件或看到「已下载」不等于安装完成。
4. 回到助手，它会自动核对各应用的设置；只剩 CC 时会直接显示「完成 Claude Code 设置」。配置好的应用可以分别继续实际使用检查。

如果某项仍未完成，当前面板会保留原因和处理入口；已有设置冲突不会被直接覆盖。可点击「复制检查摘要」联系原订单客服，不必来回切换页面、反复升级或重填卡密，也不必改动 Clash/TUN。

## 配置完成后检查应用

0.5.29 的「开始使用 → 打开应用保护检查」与「本机状态 → 查看保护检查」均打开同一个检查面板。匹配当前版本的保护组件与已完成的应用设置不再重复要求操作；旧组件仍显示更新入口。

面板提供所选浏览器的出口检测入口、Claude 桌面端入口、CC 受保护启动命令和检查摘要。实际出口、异常阻断与恢复须按面板步骤核对；打开应用或配置匹配不自动计为完整保护通过。需要协助时复制检查摘要，通过原购买订单联系提供方。

## 更新保护组件

主程序升级后，系统运行的网络扩展可能仍是旧版。0.5.29 会显示当前启用版本和安装包目标版本；存在差异时，在「应用保护检查」点击「更新保护组件」。先保存并结束 Chrome、Claude 桌面端和 CC 中的工作，完全退出所选应用，再按系统提示完成。已有的匹配过滤授权会保留，无需卸载旧扩展、重置权限或关闭 Clash/TUN。

若显示等待系统授权或等待重启，请完成对应系统步骤后回到助手检查；组件实际启用版本匹配前，不会误报已更新。随后继续完成应用设置，再核对实际出口与异常阻断。登录项配置已经保存，也不等于登录、重启或唤醒恢复已实测。

## 检查更新

**安装 0.5.30 后，可直接在助手内下载和安装后续更新。** 打开「更多工具 → 软件更新 → 检查更新」，发现新版后点击「下载安装更新」（Windows 为「在应用内下载更新」），下载和验证完成后确认安装。更新前请保存工作；确认安装后助手会重新打开，Mac 专用连接会短暂中断，已有账号、连接资料与偏好保留。

「GitHub 下载」始终作为备用选项。发现新版不会自动中断任务，下载失败或取消也会保留当前版本。macOS 若要求授权新的保护组件，仍按助手提示由本人确认。

**0.5.29 及更早版本，首次需要从上方链接手动安装 0.5.30。** 旧版本只有检查更新与 GitHub 下载能力；Mac 请按本页首次升级步骤保留服务和配置。0.5.19 及更早版本使用的 Latest 地址不包含内测包，可能提示无法读取更新信息。

内测版标记为 Pre-release，使用独立更新源，不替换正式更新。正式版发布后会在这里提供 Latest 入口，并通知内测用户升级。
