### 安装与激活

1. 下载 ZIP 并解压，将「橙格 · AI 环境助手」拖入“应用程序”。
2. 打开助手，按提示登录账号、兑换卡密、导入自己的代理连接。
3. 完成网络扩展、网络过滤和应用连接设置。系统密码由本人输入。
4. 在「本机状态 → 查看保护检查」核对组件与应用设置，再检查实际连接。

Mac 客户版自带保护组件，无需另装 LuLu。请使用安装包附件；Source code 不是安装包。

### 使用本机 Clash 前置

在「我的连接 → 更多连接设置」打开「使用前置连接」，选「本机 SOCKS5」，填写 Clash 的 SOCKS5 端口（例如 7897，地址固定为 127.0.0.1）。上方仍填写原住宅代理及原固定出口 IP。使用带账号的 HTTP／SOCKS5 住宅代理时，在连接设置下方勾选「此类型的代理认证未加密，我了解并允许本次检测」，检测通过后再应用。已有用户保留原端口与代理资料即可，无需重新导入节点。

本机前置目前搭配 HTTP／SOCKS5 固定出口，不支持 HTTPS 类型的第二跳代理。Clash 须保持运行；助手不会停用它或 TUN。固定出口失效时专用请求失败，不用前置节点作为备用出口。无需向助手导出 Clash 节点密码。

若 CC 仍显示待配置，先保存并结束 CC 任务，再在「本机状态 → 查看保护检查」点击「完成 Claude Code 设置」。第三方启动器冲突仍需按提示处理。

### 解除保护与恢复原配置

需要停止使用 CEGR 保护时，打开「本机状态」底部的「高级设置」。先保存工作并完全退出所选应用，在设备管理中仅移除本次「橙格 CEGR · 应用专用出口」描述文件，再返回点击「解除保护／恢复原配置」并确认。

**这会解除本次安装中全部所选应用的保护。解除后不再保证固定出口或断网保护，误开浏览器、Claude 桌面端或 CC 可能使用其他出口。** 如果只是暂时停用连接，请使用「诊断与维护 → 暂停连接」，保留保护。

恢复失败或有文件被保留时，按提示继续处理；不要将未完成的恢复当成已经恢复原网络。

### 软件更新与日志反馈

打开「更多工具 → 软件更新」检查新版，在应用内下载并确认安装；也可以使用本页 GitHub 下载链接。更新前请保存工作，升级本身不消耗新卡密。

旧版可先使用应用内更新；如果 1.0.0／1.0.1 仍提示“连接服务尚未完成交接”，请使用上方 ZIP 手动覆盖一次。1.0.2 的交接修复在安装新版后生效。早于 0.5.30 的版本请手动安装。保留原账号、连接记录及偏好，勿清空数据或点击“恢复原配置”。手动覆盖安装前，若旧版专用连接正在运行，请先在助手中暂停连接，再正常退出助手；重新打开后按提示恢复连接。

若出现“更新保护组件”，请保存并退出所选应用，在检查面板内完成更新及系统提示。保持现有 Clash/TUN 设置。

遇到问题后，打开「本机状态 → 导出诊断日志」保存文件，通过原购买订单发给客服，并说明发生时间、出问题的应用和具体表现。「查看保护检查」也可导出。日志从升级后开始记录，最多保存最近 240 条，写入时清理超过 7 天的记录；不会自动上传，不含连接地址、密码、卡密、令牌、账号或聊天内容。
