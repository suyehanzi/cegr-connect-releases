## 安装与升级

1. 下载 ZIP 并解压，将应用放入“应用程序”。`Source code` 不是安装包；`SHA256SUMS.txt` 用于校验下载完整性。
2. 按助手提示登录、兑换卡密、导入自己的代理连接，完成系统授权及应用设置。系统密码由本人输入，Mac 客户版无需另装 LuLu。
3. 在「本机状态 → 查看保护检查」核对设置，再检查所选应用的实际连接。Claude Code 请使用助手提供的受保护启动入口。

**先更新，再配置。** 已有用户可在「更多工具 → 软件更新」下载安装。**升级保留账号、连接和偏好，不消耗新卡密。** 更新前保存工作；若提示更新保护组件，请正常退出所选应用，按助手与 macOS 提示完成。在「本机状态 → 查看保护检查」确认系统实际启用组件为 **1.0.7（71）**，再完成应用配置和实际连接检查；只更新主程序不代表保护组件已经更新。保持原有 Clash/TUN 设置。

若 1.0.0／1.0.1 提示“连接服务尚未完成交接”，请使用上方 ZIP 手动覆盖一次；早于 0.5.30 的版本也需手动安装。手动覆盖前，先在旧助手暂停专用连接并正常退出助手，安装后按提示恢复连接。不要为升级清空数据、卸载描述文件或点击「解除保护／恢复原配置」。

## 语言与清理确认

首次设置或从旧版升级后，如出现语言与清理范围提示，请本人重新核对；已有确认记录以软件提示为准。新设置默认浏览器英文，可切换繁体中文或保持原样；已有语言选择保留。英文地区格式由本人在系统设置确认，不自动更改时区。

默认清理范围包括缓存、登录数据和 CC 本地历史。**确认偏好不会执行清理；实际清理前仍会展示清单并二次确认。清理会退出相关账号，旧 CC 会话无法直接续接。** 请先保存工作。旧浏览器清理助手需从新版重新获取后由本人加载。

Clash 须保持运行，助手不会停用它或 TUN。固定出口失效时，专用请求应停止，不以直连或前置节点作为备用出口。仍需在实际设备检查保护是否生效。

<summary>解除保护与恢复原配置</summary>

入口在「本机状态」底部的「高级设置」。先保存工作并完全退出所选应用，在设备管理中仅移除本次「橙格 CEGR · 应用专用出口」描述文件，再返回点击「解除保护／恢复原配置」并确认。

**此操作会解除本次安装中全部所选应用的保护。解除后不再保证固定出口或断网保护，误开浏览器、Claude 桌面端或 CC 可能使用其他出口。** 仅需暂时停止连接时，请使用「诊断与维护 → 暂停连接」，保留保护。

如提示恢复失败或有文件被保留，请按提示继续处理，不要视为已经恢复完成。

## 使用范围与反馈

本版已在本台完成连接稳定性、指定应用断网与恢复及本机访问隔离复验；不同客户线路、公司网络、多浏览器个人资料、睡眠／重启恢复及完整断网、防旁路保护仍未全部验收。本台测试保留了其他网络安全软件，不能视为 CEGR 单独保护的完整验收。**设置全绿、页面能打开或一次出口正确，不等于完整保护验收通过。**

公司管理策略需由公司 IT 核实；不要停用公司安全软件或关闭证书校验来排障。代理多设备并用限制以供应商规则为准。

遇到问题，在「本机状态 → 导出诊断日志」保存文件，通过原订单联系客服，并附软件版本、发生时间、应用和具体现象。日志从升级后开始记录，仅本机保存，不会自动上传。请勿在公开反馈中发送密码、卡密、令牌、聊天内容或完整代理配置。
