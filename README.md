## 下载与安装

1. 在版本页面选择适合自己电脑的安装包，先确认页面标注的系统与芯片要求。
2. 按随包使用说明安装，打开「橙格 · AI 环境助手」。
3. 登录账号，在「账号与订阅」输入购买的卡密，兑换使用时长。

同一次正式发布的 Windows 与 macOS 安装包使用相同产品版本号。具体系统支持范围以对应版本说明为准。

## 更新

可从软件中的「软件更新」检查新版，按提示完成更新；也可回到本页面下载对应系统的新版安装包。

首次正式发布后，[最新正式版本](https://github.com/suyehanzi/cegr-connect-releases/releases/latest) 将始终指向当前可下载版本。测试版不替代正式版。

升级请按版本说明操作，保留已有账号、连接记录与偏好设置。遇到安装或更新问题，请通过购买订单联系橙格客服，并提供系统版本和软件版本；不要公开发送卡密、密码或连接凭据。

## 卡密与续费

软件下载与购买卡密分开进行。已导入的未兑换卡密不设兑换期限，每张成功兑换增加 **30 天**，同一卡密重复操作不会重复加时。设备绑定及换绑按购买说明处理。

续费使用原账号兑换新卡密。软件升级本身不消耗新的卡密。
