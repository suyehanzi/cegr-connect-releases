## 选择安装包

- **Mac：Apple 芯片，macOS 14 或更新**。下载 `for-macOS-arm64.zip`。Mac 包已签名并通过 Apple 公证；本版修复扩展用途说明、执行权限和拒绝提示。
- **Windows：x64**。下载 `for-Windows-10-11-x64-Setup.exe`，退出旧版后运行安装器。Windows 10/11 客户设备仍需继续验收；当前原生测试环境为 Windows Server 2022。

请选择版本页 Assets 中的安装文件，Source code 不是安装包。Windows 安装器尚无发布者签名；若系统阻止运行，请保留提示联系提供方核对。

## Mac 已有安装的升级

先保存工作，正常退出所选浏览器、Claude 桌面端和 Claude Code。若 CEGR 专用连接正在运行，在旧助手「本机状态 → 诊断与维护」点击「暂停连接」，确认服务停止后退出助手。保留原应用和本机配置备份，再用访达将新应用覆盖到原来的「应用程序」位置。

打开新版后点击「重新连接」，本轮检查通过再启用保护。不要点击「恢复原配置」或清空账号、连接资料。暂停失败、应用仍在使用或系统拒绝时请保留提示，先联系支持。不要关闭系统安全保护。

## 检查更新

**0.5.20 及后续内测版本**可以在「更多工具 → 软件更新」检查签名更新信息，再通过「GitHub 下载」获取新版。更新由用户决定，当前内测不在应用内直接替换安装。

**Mac 0.5.19 及更早版本，首次请从上方链接手动安装 0.5.21。** 旧版本使用的 Latest 地址不包含内测版，因此可能提示无法读取更新信息。安装本版后可检查后续内测更新。

内测版标记为 Pre-release，使用独立更新源，不替换正式更新。正式版发布后会在这里提供 Latest 入口，并通知内测用户升级。

## 内测范围

本版可测试界面、账号入口、连接记录、连接检测、设备预检和更新流程。Mac 修复包已完成签名、公证和最终包验证，实际 Air 扩展激活、逐应用出口、断网阻断及服务升级仍需复验。
