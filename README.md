## 选择安装包

- **Mac：Apple 芯片，macOS 14 或更新**。下载 `for-macOS-arm64.zip`，解压后退出旧版，将应用复制到「应用程序」覆盖安装。Mac 包已签名并通过 Apple 公证。
- **Windows：x64**。下载 `for-Windows-10-11-x64-Setup.exe`，退出旧版后运行安装器。Windows 10 / 11 客户设备仍需继续验收；当前原生测试环境为 Windows Server 2022。

请选择版本页 `Assets` 中的安装文件。`Source code` 不是安装包。Windows 安装器尚无发布者签名；若系统阻止运行，请保留提示联系提供方核对。

## 更新

0.5.20 的两端内测版可在「更多工具 → 软件更新」检查签名更新信息，再通过「GitHub 下载」获取新版。更新由用户决定，当前内测不在应用内直接替换安装。

**Mac 0.5.19 及更早版本，首次请从上方链接手动安装 0.5.20。** 旧版本使用的 Latest 地址不包含内测版，因此可能提示无法读取更新信息。

内测版标记为 `Pre-release`，使用独立更新源，不替换正式更新。正式版发布后会在这里提供 Latest 入口，并通知内测用户升级。

## 内测范围

本版可测试界面、账号入口、连接记录、连接检测、设备预检和更新流程。Windows 的应用出口接管、断网保护、网络防旁路与配置恢复尚未完整接入；Mac 的真实线路、保护和升级迁移也需继续验收。**请勿将内测版当作已完成的网络保护或正式交付版。** 详细验证范围见版本说明。
