## 选择安装包

- **Mac：Apple 芯片，macOS 14 或更新**。下载 `for-macOS-arm64.zip`。Mac 为 build 54，已签名并通过 Apple 公证；本版核对系统实际启用的网络扩展版本，已授权的旧组件仍会显示更新入口；更新保留匹配的原过滤配置，明确等待授权、重启和更新失败，拒绝降级。保留原有连接及恢复能力；版本匹配仍不代表完整保护实测通过。
- **Windows：x64**。下载 `for-Windows-10-11-x64-Setup.exe`，退出旧版后运行安装器。本版同步版本并重新验证原生运行与覆盖升级。Windows 10/11 客户设备仍需继续验收；当前原生测试环境为 Windows Server 2022。

请选择版本页 Assets 中的安装文件，Source code 不是安装包。Windows 安装器尚无发布者签名；若系统阻止运行，请保留提示联系提供方核对。

## Mac 已有安装的升级

先保存工作，正常退出所选浏览器、Claude 桌面端和 Claude Code。若 CEGR 专用连接正在运行，在旧助手「本机状态 → 诊断与维护」点击「暂停连接」，确认服务停止后退出助手。保留原应用和本机配置备份，再用访达将新应用覆盖到原来的「应用程序」位置。

打开新版后只点击一次「重新连接」，服务重启可能等待 15–40 秒；等本轮连接检查通过后再继续设置。系统扩展已经授权的用户无需重复授权。不要点击「恢复原配置」或清空账号、连接资料。暂停失败、应用仍在使用或系统拒绝时请保留提示，先联系支持。不要关闭系统安全保护。

如果连接未通过，查看失败原因和「连接问题详情」，向客服提供「复制连接诊断」中的信息；不要重复系统授权或连续重连。自动重新检查时，软件会保留最近一次失败及时间。

看到「连接复核中」时，请等待自动重试。只有最近已验证的连接才会短时保留，原验证最多有效 60 秒，失败不会延长有效期；到期或发现出口不符、授权失效、网络变化等问题时，助手会关闭专用连接。软件不会自动改用直连或其他出口。

## 应用设置尚未匹配时

Mac 客户版使用随包提供的橙格网络保护扩展，不要求额外安装 LuLu。「组件版本已匹配、网络过滤已授权」之后，还需要让所选应用的连接设置生效。

1. 保存工作并完全退出所选浏览器、Claude 桌面端和 Claude Code，确认助手本轮连接检查已通过。
2. 关闭检查面板，在「本机状态 → 完成接入 → 应用设置」点击「完成设置」。助手会先配置 CC，再打开本次应用描述文件；遇到已有设置冲突时会显示原因并保留原文件。
3. 在系统设置的「设备管理」安装「橙格 CEGR · 应用专用出口」。系统密码或要求本人确认的步骤由本人完成。仅打开文件或看到「已下载」不等于安装完成。
4. 回到助手刷新状态，确认「应用设置符合当前方案」，再打开应用保护检查，逐项验证实际使用和保护。

若仍未匹配，请记录「完成设置」后的准确提示，向客服提供检查摘要。需要分别核对浏览器/桌面端受管策略和 CC 设置；不必反复升级、重填卡密或改动 Clash/TUN。

## 配置完成后检查应用

0.5.28 的「开始使用 → 打开应用保护检查」与「本机状态 → 查看保护检查」均打开同一个检查面板。匹配当前版本的保护组件与已完成的应用设置不再重复要求操作；旧组件仍显示更新入口。

面板提供所选浏览器的出口检测入口、Claude 桌面端入口、CC 受保护启动命令和检查摘要。实际出口、异常阻断与恢复须按面板步骤核对；打开应用或配置匹配不自动计为完整保护通过。需要协助时复制检查摘要，通过原购买订单联系提供方。

## 更新保护组件

主程序升级后，系统运行的网络扩展可能仍是旧版。0.5.28 会显示当前启用版本和安装包目标版本；存在差异时，在「应用保护检查」点击「更新保护组件」。先保存并结束 Chrome、Claude 桌面端和 CC 中的工作，完全退出所选应用，再按系统提示完成。已有的匹配过滤授权会保留，无需卸载旧扩展、重置权限或关闭 Clash/TUN。

若显示等待系统授权或等待重启，请完成对应系统步骤后回到助手检查；组件实际启用版本匹配前，不会误报已更新。随后继续完成应用设置，再核对实际出口与异常阻断。登录项配置已经保存，也不等于登录、重启或唤醒恢复已实测。
